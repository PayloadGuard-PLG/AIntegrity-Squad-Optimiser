### Simple carry is falsified

A single conserved fractional phase with exactly 1.35 subtracted each run and
integer floor-state rendering cannot produce the ordered sequence. In
particular the data contain clean adjacent -2/-2 outcomes. With fractional step
0.35, that accumulator cannot cross an extra integer boundary on consecutive
runs. Exhaustive phase scanning gives no admissible initial phase.

This matters: the experiment does **not** justify adding a hidden decimal
remainder to Resource Coach.

## Consequence for Resource Coach

The right first test is now **not** "add fractional carry." It is to preserve
the current continuous player-response model and insert a research-only
observation layer downstream:

[
\mu \longrightarrow Y \in \mathbb Z.
]

The zero-parameter stochastic candidate is the unbiased quantizer

[
Y=\lfloor\mu\rfloor+\operatorname{Bernoulli}(\{\mu\}),
\qquad E[Y]=\mu.
]

That gives a falsifiable prediction: an observed endpoint generated by this
one-step renderer must be either `floor(mu)` or `ceil(mu)`, with frequencies
calibrated by the fractional part.

This branch therefore compares continuous scoring, floor, nearest, ceil,
floor/ceil support, and the stochastic likelihood **without changing the
upstream age/tier/dose/shape parameters**. A one-parameter count renderer is
permitted only after the zero-parameter model is scored and falsified or shown
insufficient.

See `preregistration-20260924.json` for the frozen rules.
